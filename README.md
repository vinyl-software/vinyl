# Vinyl

Vinyl is a desktop app for DJs, producers and content creators to create videos and reels from their music.

This is the **public repository** for Vinyl.

## Downloads

The latest installers are available directly in this repository.

Choose the appropriate installer for your operating system from the available builds.
